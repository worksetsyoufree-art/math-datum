# math-datum

Датумы и системы координат, применяемые в России: федеральные (СК-42, СК-95, ПЗ-90, ПЗ-90.11, ГСК-2011) и
региональные/городские местные системы координат (МСК), с проверкой работоспособности.

## Что внутри

| Файл | Содержимое |
|---|---|
| `data/msk_systems.json` / `.csv` | 490 определений МСК (зона = запись): проекция Гаусса–Крюгера, эллипсоид, осевой меридиан, ложные координаты, параметры перехода, готовая строка PROJ |
| `data/federal_datums.json` | 16 федеральных СК из реестра EPSG (через pyproj): эллипсоид, область применения, доступные преобразования в WGS 84 и их точность |
| `data/region_capitals.csv` | Контрольные точки (столицы регионов), по которым проверяются зоны |
| `data/validation_regions.csv` | Результат проверки по регионам (лучшая зона, E/N, смещение от осевого меридиана) |
| `data/validation_points.csv` | То же для каждой зоны (494 пары «зона × точка») |
| `data/validation_summary.json` | Итоги: проверка знаков поворотов, сдвиги федеральных датумов, регионы без данных |
| `data/raw/` | Сырые выгрузки с сайтов и `source_conflicts.json` |
| `scripts/` | `scrape_*.py` → `parse_msk.py` → `build_dataset.py` → `validate.py` |

Воспроизведение: `python3 -I scripts/scrape_geoprof.py && python3 -I scripts/scrape_tg.py && python3 -I scripts/parse_msk.py && python3 -I scripts/build_dataset.py && python3 -I scripts/validate.py`
(нужны `requests`, `beautifulsoup4`, `lxml`, `pyproj`).

## Источники

* [geoprof.nethouse.ru](https://geoprof.nethouse.ru/parametry-mestnyh-sistem-koordinat) — страница на каждый субъект, строки MapInfo `.prj` (79 страниц).
* [terraingis.ru](https://terraingis.ru/category/dannye-dlya-gis/msk) — раздел «Местные системы координат» (70 страниц), включая МСК-90 (Крым и Севастополь), МГГТ, внутрикраевые МСК Красноярского края.
* Реестр EPSG (через pyproj 3.8 / PROJ 9.8) — федеральные датумы и эталонная операция EPSG:5044.

260 записей подтверждены обоими сайтами, 140 — только terraingis, 90 — только geoprof.
Не использованы: inner.su (SEO-страница с ошибочными параметрами, например у СК-95 указан сдвиг ПЗ-90), mapbasic.ru (недоступен через прокси, 502).

## Важно: знаки поворотов

В строках MapInfo/ГОСТ Р 51794-2008 повороты заданы в конвенции *coordinate frame* (`-0.35, -0.79`). В PROJ `+towgs84` — *position vector*, знаки поворотов нужно инвертировать (`0.35, 0.79`). В `proj4` каждой записи это уже сделано.
Проверено: инвертированный вариант совпадает с EPSG:5044 до 0.000 см, неинвертированный даёт ошибку до **29.9 м**.

Варианты в данных: `gost2008` — параметры ГОСТ (`9999` в MapInfo), `calc` — «расчётные» (датум MapInfo `1001`, параметров перехода в источнике нет; для PROJ принят ГОСТ-сдвиг, поле `towgs84_basis` это отмечает).

## Результаты проверки

* Для каждой записи МСК прогнан WGS 84 → МСК → WGS 84 на столицах регионов: максимальная невязка 0.96 мм (линеаризованный Гельмерт в PROJ не точно обратим; допуск 5 мм).
* Столица региона должна попасть в одну из зон своего региона (|E − E₀| ≤ 260 км). **154 из 154 проверок (регион × город × вариант) пройдены**; лучшая зона в среднем в 49 км от осевого меридиана, максимум 160 км (Ханты-Мансийск).
* Федеральные датумы, сдвиг в WGS 84 (Москва): Пулково-1942 ≈ 117 м, Пулково-1995 ≈ 116 м, ПЗ-90 ≈ 3 м, ПЗ-90.11 ≈ 0.7 м, ГСК-2011 ≈ 0.1 м. Для Pulkovo 1942(58) и (83) в EPSG нет преобразования в WGS 84 (сдвиг 0).

## Ограничения и найденные проблемы

* **Проверка подтверждает осевой меридиан и ложный восток, но не ложный север.** Ложный север независимой проверке не поддаётся без опорных пунктов с известными координатами в каждой МСК — это следующий шаг (пункты ГГС / кадастровые выписки).
* Контрольные точки (`region_capitals.csv`) введены вручную с точностью около 0.01°, независимо не сверялись.
* **Нет данных:** Тыва (17), Еврейская АО (79), ЯНАО (89), новые регионы (Донецк, Луганск, Запорожье, Херсон), равно как и ряд подсистем (кадастровые округа, городские СК кроме Москвы и Петербурга). Росреестровского каталога в открытом виде найти не удалось; на форумах упоминается около 30 тысяч МСК по стране, здесь собрана только региональная основа.
* **Аномалия в источнике:** МСК-19 (166), Хакасия — в ГОСТ-строке `lat0 = 0.37`, в расчётной `0`; помечено в поле `flag` (`MSK0106`, `MSK0107`). Исходя из остальных данных, вероятна опечатка.
* **Конфликт источников:** МГГТ (Москва) — у geoprof ложные координаты `0, 0`, у terraingis `16.098, 14.512`; запись geoprof помечена `conflict`.
* МСК-09 имеет ненулевую широту начала `0.099789°` — как в источнике, не проверялось.
