# Тестовые данные: точки → датум

## `nist_l2/` — эталонные пары NIST (МНК-подгонка)

Источник: NIST Dimensional Metrology Group, Algorithm Testing System —
<https://www.nist.gov/dimensional-metrology-group/algorithm-testing>
(архив «NIST-L2-reference-pairs», автор C. Shakarji). Инструкция — `nist_l2/NIST-instructions.pdf`.
NIST разрешает использовать эти данные для внутреннего самотестирования ПО (это не замена официальной проверке).

240 наборов, по 30 на каждый тип: `Line2d`, `Line3d`, `Plane`, `Circle2d`, `Circle3d`, `Sphere`, `Cylinder`, `Cone`.
Наборы сгенерированы по ASME B89.4.10-2000: размеры от 1 до 500 мм, положение до 1000 мм, до 500 точек, есть частичные элементы (дуги, сегменты).

- `*.ds`: первая строка — число точек, далее строки `x y z` (разделитель — табуляция, CRLF).
- `*.fit` — эталонная МНК-подгонка:

| Элемент | Числа |
|---|---|
| Line | точка (3), направляющие косинусы (3) |
| Plane | точка (3), нормаль (3) |
| Circle | центр (3), нормаль (3), диаметр |
| Sphere | центр (3), диаметр |
| Cylinder | точка на оси (3), ось (3), диаметр |
| Cone | точка на оси (3), ось в сторону роста радиуса (3), расстояние от точки до поверхности, полный угол при вершине в градусах |

Окружности в 3D подгоняются так: сначала МНК-плоскость, затем окружность по точкам, спроецированным на неё.

## `synthetic/` — сгенерированные примеры с точным ответом

Генератор: `python tools/generate_cases.py` (фиксированный seed). Проверка: `python tools/verify_cases.py`.
Эталоны построены методом нуль-пространства: отклонения точек ортогональны условиям оптимальности метода подгонки. Поэтому ожидаемый ответ точен и при шуме.

| Тип (`type`) | Файлы | Что найти |
|---|---|---|
| `plane_lsq` | `plane_lsq_01…06` | МНК-плоскость (точка + нормаль). Есть 3 и 4 точки без шума, до 500 точек, частичная выборка |
| `flatness_minimum_zone` | `flatness_mz_01…03` | Плоскостность по минимальной зоне (Чебышёв) и датум-плоскость, касательная снаружи материала (ISO 5459) |
| `datum_system_321` | `datum_321_01…04` | Система датумов A\|B\|C (3-2-1): начало и оси. В `_04` есть выбросы в A, нужен робастный метод |
| `best_fit_to_nominal` | `best_fit_01…03` | Совмещение точек с номинальной моделью (брус): R, t |

Общие поля JSON: `points` (или `datums.{A,B,C}.points`), `expected`, `tolerance`, `notes`.
Определения в `datum_system_321`:
- Z — нормаль A, Y — нормаль B (B ⟂ A), X — нормаль C (C ⟂ A, B).
- Оси направлены в материал (`material_direction_hint`).
- Начало — пересечение трёх плоскостей.

## Где искать ещё

- **PTB TraCIM** (<https://tracim.ptb.de>): онлайн-сервис сертификации, выдаёт наборы и сверяет результат (Gauss и Chebyshev). Нужна регистрация, услуга платная.
- **M. Forbes, «Generation of numerical artefacts…»** (Measurement: Sensors, 2021) и статья в IJMQE 2013: методика генерации эталонов минимальной зоны и МНК. Наш генератор использует тот же принцип.
- **C. Shakarji, NIST J. Res. 1998:** описание эталонных МНК-алгоритмов, <https://www.ncbi.nlm.nih.gov/pmc/articles/PMC4890955/>.
