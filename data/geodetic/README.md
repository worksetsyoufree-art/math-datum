# Геодезические датасеты по субъектам РФ

Каждый файл содержит точки и ожидаемый результат для задач «точки → параметры перехода (датум)» и «локализации» ГНСС.

| Файл | Что это |
|---|---|
| `regions/<ISO 3166-2>.json` | 83 субъекта, по 3 задачи в каждом (см. ниже) |
| `index.csv` | сводка по регионам: невязки локализации, масштаб, разворот |
| `regions.geojson` | границы субъектов, по которым выбирались точки (Natural Earth 10m admin-1, public domain, упрощено до 0.01°) |
| `gost_32453_parameters.json` | параметры перехода между СК-42, СК-95, ГСК-2011, ПЗ-90.x, WGS-84, ITRF-2008 по ГОСТ 32453-2017 |
| `gost_32453_control_example.json` | контрольный пример ГОСТ (пункт Менделеево) |

Генерация: `python tools/generate_geodetic.py`. Проверка: `python tools/verify_geodetic.py`.
Пересчёты в обоих скриптах — функции библиотеки `mathdatum.datums` (BLH ↔ XYZ, 7 параметров ГОСТ, поперечный
Меркатор); переход на них с pyproj не изменил ни одного байта данных. Проверка дополнительно сверяет их с PROJ.
Зависимости перечислены в `requirements.txt`. Seed фиксирован, поэтому результат воспроизводится.

## Задачи в файле региона (`tasks`)

### 1–2. `helmert_7p`: переход СК-42 → ПЗ-90.11 по 7 параметрам

- **Данные:** 15 точек внутри субъекта. Для каждой даны B, L, H в СК-42 и геоцентрические XYZ в обеих системах.
- **Ответ:** параметры ГОСТ 32453-2017, прил. А.1: ΔX = 23.557, ΔY = −140.844, ΔZ = −79.778 м; ωx = −0.00230″, ωy = −0.34646″, ωz = −0.79421″; m = −0.228 ppm.
- **Модель:** формула ГОСТ, то есть поворот системы координат с малыми углами. В PROJ это `+proj=helmert +convention=coordinate_frame`.
- **Варианты:**
  - `exact`: шума нет, есть только округление до 0.1 мм.
  - `noisy`: шум 2 см построен ортогонально якобиану, поэтому параметры ГОСТ остаются точным решением МНК.
- **Важно:** на сети размером с регион сдвиги и повороты почти неразличимы, матрица плохо обусловлена. Решение надо центрировать. Проверять лучше по прогнозу координат, а не по самим параметрам.

### 3. `site_localization`: локализация ГНСС на участке (~5 км)

Это то же, что «калибровка» или «локализация» в полевом ПО.

- **Данные:**
  - 6 опорных (`control_points`) и 4 контрольных (`check_points`) пункта.
  - Для каждого пункта: ГНСС-координаты в ПЗ-90.11 (B, L, h), они же в рабочей проекции (`working_projection`, поперечный Меркатор на эллипсоиде ПЗ-90.11), и каталожные координаты в местной системе x, y, H.
- **Ответ:**
  - **План:** преобразование подобия (4 параметра) в рабочей проекции: `[x, y] = [tx, ty] + [[a, −b], [b, a]]·([N, E] − центроид)`. Параметры a, b, tx, ty, а также масштаб в ppm и разворот в секундах.
  - **Высота:** наклонная плоскость `H = h + c0 + c1·dN + c2·dE`.
  - **Проверка:** невязки на опорных пунктах, прогноз и ошибки на контрольных.
- **Точность ответа:** ответ — точное решение МНК по данным из файла (допуск 1e-9 для параметров, 1 мм для координат).
- **Как сделаны данные** (блок `truth`, для оценки точности):
  - ГНСС-координаты получены из СК-42 по ГОСТ.
  - Местная система — **синтетическая** «псевдо-МСК»: Гаусс–Крюгер на эллипсоиде Красовского со сдвинутым осевым меридианом и ложными смещениями, как устроены МСК.
  - Аномалия высоты задана гладкой поверхностью.
  - Шум: ГНСС 1/2 см (план/высота), каталог 5 мм.

## Ограничения

- **Псевдо-МСК не настоящие.** Параметры МСК субъектов (ключи) выдаёт Росреестр, в открытом доступе их нет. Здесь они сгенерированы случайно. Реальные ключи и каталоги пунктов ГГС в репозиторий не кладутся.
- **Состав субъектов** соответствует объектам с кодом ISO 3166-2 `RU-*` в Natural Earth (83). Другой набор границ можно подставить в `regions.geojson`.
- **Контрольный пример ГОСТ** проверяется на всех трёх шагах (`mathdatum.datums`): 1 — перенос эпохи 2005 → 2010
  по скорости пункта; 2 — ITRF-2008 → ПЗ-90.11 по обратным параметрам прил. Д.1 (эпоха 2010.0), расхождение
  4.3e-5 м при значениях ГОСТ до 0.1 мм; 3 — перенос 2010 → 2013.9 той же скоростью пункта, 2.3e-4 м при значениях
  до 1 мм. Модели скоростей не нужны: используется скорость пункта из примера.
- **Параметры СК-95 (прил. А.3):** знак ωy исправлен на +0.00354″ (было −0.00354″). Наборы А.1, А.3, В.1, Г.1 —
  композиция параметров ГОСТ Р 51794-2008 (→ ПЗ-90.02) с прил. Б.1 (ωy = +0.00354″); все остальные наборы файла
  с ней совпадают до последнего знака. Задачи регионов используют только А.1 и не изменились.
