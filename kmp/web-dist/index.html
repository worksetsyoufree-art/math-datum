Локализация ГНСС

Пары точек ГНСС ↔ местная система → датум → пересчёт координат; пересчёты между СК-42, СК-95, ГСК-2011, ПЗ-90.x, WGS-84, ITRF-2008 по ГОСТ 32453-2017. Все расчёты выполняются в браузере (Kotlin/JS, модуль :localization).

1. Пары точек

Формат: name;B;L;h;x;y;H;use. B, L — градусы в системе ГНСС-измерений (ниже), h — высота ГНСС; x — север, y — восток, H — местная высота. use: both, plan, height или none (контрольная точка). Необязательные столбцы sigma_plan;sigma_height — априорная СКО точки, м (каталог и ГНСС вместе: √(σкат² + σГНСС²)); точка получает вес p = σ0² / σ², пусто — глобальная σ0.

2. Датум

|w| — нормированная поправка (тест Баарда; априорная СКО 20 мм в плане на координату, 30 мм по высоте — единица веса σ0; порог 3.29). σ — использованные СКО точек, свои выделены. Подсвечено |w| выше порога — вероятна грубая ошибка; точки автоматически не исключаются. «Без точки» — ошибка прогноза в точке датумом, рассчитанным без неё; «—» — проверить нельзя (без точки модель не определена).
